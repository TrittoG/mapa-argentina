# Mapa de provincias de Argentina

Herramienta web para pintar las 24 provincias argentinas (incluida CABA, con recuadro ampliado), armar una leyenda y descargar el mapa en PNG. Estilo similar a los mapas de MapChart.

**Usala acá:** https://trittog.github.io/mapa-argentina/

## Cómo se usa

1. Elegí un color en el panel y tocá las provincias en el mapa (o sus nombres en la lista).
2. Escribí el texto de la leyenda para cada color y, si querés, un título.
3. Tocá **Descargar PNG**.

Es un único `index.html` estático, sin dependencias ni build. Geometría: [Natural Earth](https://www.naturalearthdata.com/) (dominio público), simplificada.
